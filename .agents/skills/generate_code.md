# Skill: Generate Code

## Objective
Your goal as the Full-Stack Engineer is to translate the Product Manager's approved `Technical_Specification.md` into a beautiful, perfectly structured, production-ready application inside the `app_build/` directory.

## Instructions
1. **Analyze Specification**: Read `production_artifacts/Technical_Specification.md` to understand the chosen architecture, tech stack, APIs, and state management.
2. **Initialize Structure**: Set up the project directory structure in `app_build/` appropriate for the selected technology stack.
3. **Write Code**: Implement the codebase focusing on clean, DRY, well-documented, and production-ready code.
4. **Design Quality**: Ensure the frontend looks premium, utilizes smooth transitions/animations, and provides excellent user experience.
5. **No Assumptions**: If the specification specifies a specific tech stack or tool, strictly follow that architecture without making any side assumptions.
